How the two systems link

Zentra Realty owns the agent, the commission and the paperwork; Zentra Push owns the channels a listing reaches. Either intake form can be the point of entry. When the agent has an account on both, the record is written to both and the link is stored — an edit on one side updates the other. When the agent has no Zentra Push account, the listing simply stays inside Zentra Realty: nothing is blocked, and a later link backfills the push record instead of asking for the same details twice. The same is true in reverse on the Zentra Push side.
